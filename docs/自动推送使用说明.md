# Weekly Refresh 自动推送使用说明

## 📋 概述

`weekly_refresh_and_push.sh` 脚本已升级，现在可以**自动推送主仓库和子模块**到 GitHub。

## 🎯 功能

脚本会自动完成以下步骤：

1. 🔄 从 Lovable 同步最新改动
2. 📥 运行 weekly refresh，获取最新鸟类数据
3. 📝 更新 location_birds manifest
4. 🚀 **提交并推送子模块**（feather-flash-quiz）
5. 🚀 **提交并推送主仓库**（包括子模块引用）到 main 和 develop_lovable
6. 🔄 同步改动到 Lovable

## 🚀 使用方法

### 基础用法（默认7天）

```bash
bash tools/weekly_refresh_and_push.sh
```

### 自定义天数

使用环境变量 `REFRESH_DAYS` 设置查询天数：

```bash
# 查询30天
REFRESH_DAYS=30 bash tools/weekly_refresh_and_push.sh

# 查询15天
REFRESH_DAYS=15 bash tools/weekly_refresh_and_push.sh
```

### 指定地点

如果要只更新特定地点，需要修改脚本中的命令行参数：

```bash
# 编辑脚本的第29行
python3 tools/run_weekly_refresh.py --locations "芜湖市" --days "${REFRESH_DAYS}"
```

## 📊 执行流程

```
🔄 从 Lovable 同步
    ↓
▶️  运行 weekly refresh
    ↓
🔄 更新 manifest
    ↓
📦 检查子模块改动
    ├─ 有改动 → 提交 + 推送子模块
    └─ 无改动 → 跳过
    ↓
📦 检查主仓库改动
    ├─ 有改动 → 提交 + 推送到 main 和 develop_lovable
    └─ 无改动 → 跳过
    ↓
🔄 同步到 Lovable
    ↓
✨ 完成
```

## ⚙️ 配置说明

### 环境变量

- `REFRESH_DAYS`: 查询天数（默认 7）
- `COMMIT_MSG`: 子模块提交信息（默认 "chore: weekly refresh YYYY-MM-DD"）

### 配置文件

地点配置在 `config/birdreport_locations.json`：
- `default_days`: 每个地点的默认查询天数
- 如果脚本未指定 `--days` 参数，会使用配置文件中的 `default_days`

示例（芜湖市配置）：
```json
{
  "id": "wuhu_shi",
  "name": "芜湖市",
  "province": "安徽省",
  "city": "芜湖市",
  "default_days": 30,
  "query_level": "city"
}
```

## 🔍 注意事项

1. **Git 配置**: 确保已配置 git 用户信息
   ```bash
   git config --global user.name "Your Name"
   git config --global user.email "your.email@example.com"
   ```

2. **eBird Token**: 确保 `config/ebird_token.sh` 文件存在（用于下载鸟叫声）

3. **网络连接**: 需要稳定的网络连接来下载图片、上传 Cloudinary、推送 GitHub

4. **自动推送**: 脚本会**自动推送到 GitHub**，请确保改动正确后再运行

## 🆚 对比手动方式

### 使用脚本（推荐）
```bash
bash tools/weekly_refresh_and_push.sh
```
✅ 一键完成所有步骤
✅ 自动推送主仓库和子模块
✅ 自动同步到 Lovable

### 手动方式
```bash
# 1. 运行 refresh
python3 tools/run_weekly_refresh.py

# 2. 更新 manifest
cd feather-flash-quiz
node scripts/generate-location-birds-manifest.js

# 3. 提交推送子模块
git add -A && git commit -m "..." && git push

# 4. 提交推送主仓库
cd ..
git add -A && git commit -m "..." 
git push origin main
git push origin main:develop_lovable

# 5. 同步到 Lovable
bash tools/sync_to_lovable.sh
```
❌ 步骤繁琐
❌ 容易遗漏步骤

## 🐛 故障排查

### 问题：子模块推送失败

可能是分支冲突，手动解决：
```bash
cd feather-flash-quiz
git status
git pull --rebase origin main
# 解决冲突后
git push origin main
```

### 问题：主仓库推送失败

检查是否有本地未提交的改动：
```bash
git status
git stash  # 暂存改动
# 重新运行脚本
```
