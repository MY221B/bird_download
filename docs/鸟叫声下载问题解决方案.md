# 鸟叫声下载问题解决方案

## 问题分类

鸟叫声下载失败的主要原因：

### 1. eBird 数据库中无此物种
某些鸟类的学名在 eBird 数据库中找不到对应的 species code。

**解决方案**：
- 使用 `find_ebird_code.py` 工具手动查找
- 添加到手动映射文件 `config/ebird_manual_mapping.json`

### 2. Macaulay Library 中找不到音频
即使找到了 eBird code，Macaulay Library 也可能没有该物种的音频资源。

**解决方案**：
- 访问 https://search.macaulaylibrary.org 手动搜索
- 如果确实没有音频，这是正常的（不是所有鸟类都有录音）

### 3. 缺少学名
鸟类的 JSON 文件中缺少 scientific_name 字段。

**解决方案**：
- 补全 JSON 文件中的学名信息
- 或添加到手动映射文件

## 工具使用

### 1. 查找 eBird Species Code

```bash
# 使用英文名查找
python3 tools/find_ebird_code.py "Japanese Tit"

# 使用学名查找
python3 tools/find_ebird_code.py "Parus minor" --scientific
```

### 2. 添加手动映射

编辑 `config/ebird_manual_mapping.json`:

```json
{
  "mappings": {
    "Japanese Tit": "gretit1",
    "新鸟类英文名": "ebird_code"
  }
}
```

### 3. 重新下载鸟叫声

```bash
# 下载单个鸟类
python3 tools/batch_download_sounds.py --bird bird_slug

# 重新运行周更新（会自动下载缺失的叫声）
bash tools/weekly_refresh_and_push.sh
```

## 常见问题

### Q: 为什么有些鸟类总是下载失败？
A: 可能是以下原因之一：
1. 该物种在 eBird 数据库中使用了不同的学名
2. 该物种在 Macaulay Library 中没有录音资源
3. 网络问题

### Q: 如何知道某个鸟类的正确 eBird code？
A: 使用提供的工具：
```bash
python3 tools/find_ebird_code.py "鸟类英文名"
```

### Q: 手动映射文件在哪里？
A: `config/ebird_manual_mapping.json`

### Q: 如何手动下载单个鸟类的叫声？
A: 
```bash
python3 tools/batch_download_sounds.py --bird 鸟类slug
```

## 技术细节

### eBird API
- 端点: `https://api.ebird.org/v2/ref/taxonomy/ebird`
- 需要 API Token (环境变量 `EBIRD_TOKEN`)
- 返回所有物种的完整 taxonomy

### Macaulay Library API
- 端点: `https://search.macaulaylibrary.org/api/v1/search`
- 使用 eBird species code 作为 taxonCode
- 按评分排序，选择最高分的音频
