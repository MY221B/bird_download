# 鸟叫声功能 - 使用与集成说明

## 📋 概述

鸟叫声功能已完全集成到 weekly refresh 自动化流程中。每次运行 `weekly_refresh_and_push.sh` 时，系统会自动：

1. 检查哪些鸟类缺少叫声
2. 从 Macaulay Library 下载音频（按质量排序）
3. 上传到 Cloudinary 托管
4. 更新 JSON 文件，添加 sounds 字段
5. 提供详细的成功/失败日志

技术实现：通过 eBird API 获取 species code，从 Macaulay Library 搜索音频（按质量排序），下载最高质量 MP3，上传至 Cloudinary 的 `bird-gallery/{slug}/sounds/` 目录。

---

## 🚀 使用方法

### 方式一：正常运行 Weekly Refresh（推荐）

```bash
# 运行 weekly refresh，会自动处理图片和声音
bash tools/weekly_refresh_and_push.sh

# 自定义刷新天数
REFRESH_DAYS=14 bash tools/weekly_refresh_and_push.sh

# 只处理特定地点
python3 tools/run_weekly_refresh.py --locations 圆明园 奥森北园
```

**注意**: weekly_refresh_and_push.sh 现在会自动加载 eBird Token（修复了 52 种鸟都失败的问题）

**流程说明**：
1. 抓取各地点的鸟类数据
2. 检查并下载缺失的图片
3. 上传图片到 Cloudinary
4. **→ 自动检查并下载缺失的叫声**
5. 更新 JSON 并复制到 location_birds 目录
6. 自动提交并推送到 GitHub

### 方式二：手动同步已有的 location_birds

如果 location_birds 目录中的 JSON 文件是旧的（没有 sounds 字段），可以运行：

```bash
# 同步主目录的 sounds 字段到所有 location_birds JSON
python3 tools/sync_sounds_to_location_birds.py
```

这会：遍历所有地点和日期的 JSON 文件，从主目录复制 sounds 字段，只更新缺失或过期的 sounds 数据。

### 方式三：单独运行声音下载

```bash
# 为特定鸟类下载声音
source config/ebird_token.sh
python3 tools/auto_sounds_refresh.py bluetail marsh_tit

# 批量下载（使用 JSON 文件）
python3 tools/batch_download_sounds.py birds_list.json sounds_download
python3 tools/batch_upload_sounds.py sounds_download/download_record.json
```

### 单物种测试（底层脚本）

```bash
source config/ebird_token.sh
python3 tools/test_fetch_bird_sounds.py "Red-flanked Bluetail" "Tarsiger cyanurus" bluetail
python3 tools/upload_sounds_to_cloudinary.py bluetail test_sounds/bluetail_134560971.mp3
```

## 🔧 技术要点

### JSON 结构（sounds 字段）

```json
{
  "bird_info": { ... },
  "macaulay": [ ... ],
  "sounds": [
    {
      "original_file": "bluetail_134560971.mp3",
      "url": "https://res.cloudinary.com/dzor6lhz8/video/upload/v1764318180/bird-gallery/bluetail/sounds/bluetail_134560971.mp3",
      "public_id": "bird-gallery/bluetail/sounds/bluetail_134560971",
      "duration": 14.472,
      "format": "mp3",
      "bytes": 262028,
      "attribution": {
        "recordist": "Unknown",
        "source": "macaulay",
        "source_id": "134560971",
        "asset_url": "https://macaulaylibrary.org/asset/134560971",
        "license": "© Cornell Lab of Ornithology (non-commercial use)",
        "license_url": "https://support.ebird.org/en/support/solutions/articles/48001064570"
      }
    }
  ]
}
```

### API 端点

- **音频搜索**: `https://search.macaulaylibrary.org/api/v1/search?taxonCode={code}&mediaType=a&sort=rating_rank_desc`
  - `mediaType=a` - 音频类型
  - `sort=rating_rank_desc` - 按质量排序
- **音频下载**: `https://cdn.download.ams.birds.cornell.edu/api/v1/asset/{asset_id}/audio`

### Cloudinary 配置

- **resource_type**: `video`（音频也使用 video 类型）
- **存储路径**: `bird-gallery/{slug}/sounds/`
- **URL 格式**: `https://res.cloudinary.com/dzor6lhz8/video/upload/v{version}/bird-gallery/{slug}/sounds/{filename}.mp3`

## ❌ 常见失败原因

### 1. eBird 数据库中无此物种
**原因**: 该物种未被 eBird 收录，或学名不匹配  
**解决**:
- 使用 `find_ebird_code.py` 工具手动查找正确的 code：
  ```bash
  python3 tools/find_ebird_code.py "Japanese Tit"         # 用英文名查找
  python3 tools/find_ebird_code.py "Parus minor" --scientific  # 用学名查找
  ```
- 找到后添加到手动映射文件 `config/ebird_manual_mapping.json`：
  ```json
  {
    "mappings": {
      "Japanese Tit": "gretit1",
      "新鸟类英文名": "ebird_code"
    }
  }
  ```

### 2. Macaulay Library 中找不到音频
**原因**: 该物种没有音频记录，或音频质量不符合标准  
**解决**: 访问 https://search.macaulaylibrary.org 手动搜索确认；确实没有则正常跳过

### 3. 缺少学名
**原因**: 鸟类 JSON 文件中缺少 `scientific_name` 字段  
**解决**: 补全 JSON 文件中的学名，或添加到手动映射文件

### 4. 音频下载失败
**原因**: 网络问题或 Macaulay 服务器问题  
**解决**: 重新运行脚本，或使用代理

### 5. Cloudinary 上传失败
**原因**: 网络问题或 Cloudinary 配额已满  
**解决**: 检查网络连接；登录 Cloudinary 后台检查存储空间；重新运行脚本

### 6. JSON 更新失败
**原因**: 文件权限问题或 JSON 格式错误  
**解决**: 检查文件权限，手动修复 JSON 格式

## 🆘 故障排除

### 问题：所有下载都失败

**检查清单**:
1. [ ] EBIRD_TOKEN 是否设置？ → `echo $EBIRD_TOKEN`
2. [ ] 网络是否正常？ → `ping api.ebird.org`
3. [ ] curl 是否可用？ → `which curl`
4. [ ] Python 环境是否正确？ → `python3 --version`

### 问题：部分鸟类下载失败

1. 查看失败原因（在日志中）
2. 若是「eBird 无记录」，检查学名是否正确
3. 若是「Macaulay 无音频」，记录下来，暂时跳过
4. 若是「下载失败」，重试几次

### 问题：JSON 更新失败

1. 检查文件权限：`ls -l cloudinary_uploads/`
2. 验证 JSON 格式：`python3 -m json.tool cloudinary_uploads/xxx.json`
3. 手动修复或重新生成 JSON
